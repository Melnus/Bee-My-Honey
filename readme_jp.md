# Bee My Honey - ハニカム電子取引所 (Bee Exchange)

Minecraft Bedrock Edition 向けの経済シミュレーション・アドオンです。世界の働き者のハチたちが集めた資産を元手に、外貨為替、配当のある株式投資、宝石などの現物資産取引、先物取引、利子のつく銀行預金、動物や行商人との交易、そしてオフライン決済も可能なコールドウォレットまで、幅広い経済活動を体験できます。

## 概要

本アドオンを導入すると、ワールド内の巣箱や養蜂箱を通じて「ハニカム電子取引所」へアクセスできるようになります。
所持品のエメラルドを電子マネーとして預け入れ、5種類の外貨や5銘柄の株式を売買して資産を運用できます。

---

## 基本的な遊び方

### 取引所の開き方
1. 「本（minecraft:book）」をメインハンドに持ちます。
2. 設置されている「養蜂箱（beehive）」にインタラクト（右クリック / タップ）すると、メインメニュー（口座管理・外貨為替・株式・先物・コールドウォレット）が開きます。
3. 「ミツバチの巣（bee_nest）」にインタラクトすると、下記の「動物交易」にあるハチとの交易窓口へ直接アクセスできます（追加の準備は不要です）。

### その他のインタラクトポイント
養蜂箱・ミツバチの巣以外にも、本でインタラクトすると反応するブロックがあります。誤爆防止のため、いずれも「真上に植木鉢（何か植わっていても可）を置くこと」が条件です。

| ブロック | 植木鉢が必要か | 開く機能 |
| :--- | :---: | :--- |
| 白色の羊毛 (white_wool) | 必要 | 行商人の召喚 |
| 鉄ブロック (iron_block) | 必要 | ゴーレムの現物資産取引 |
| 干し草の俵 (hay_block) | 必要 | 動物交易 — リンゴ |
| トウヒの原木 (spruce_log) | 必要 | 動物交易 — スイートベリー |
| 苔ブロック (moss_block) | 必要 | 動物交易 — グローベリー |
| エンドストーンレンガ (end_bricks) | 必要 | 動物交易 — コーラスフルーツ |

## 主な機能

### 1. 口座管理 (Bank)
- 所持品のエメラルドを電子残高（E）として口座に預け入れたり、逆に口座から手元へエメラルドを引き出すことができます。
- すべての金融商品はこの電子残高（E）を使用して取引を行います。
- 引き出し時や配当受け取り時にインベントリが満杯の場合は、アイテムが足元にドロップするためロストしません。

### 2. 外貨為替市場 (Forex)
価格変動の波を持つ5種類の外貨を売買できます。通貨ごとに基準レートと変動率（ボラティリティ）が異なります。

- ハニカム (HNY): 基軸通貨。手堅く安定した推移。
- リンゴ (APL): 緩やかな波型を描く標準的な通貨。
- スイートベリー (SWB): 単価が安く、激しく乱高下するハイボラティリティ型。
- グローベリー (GLB): 伸びしろのある成長型。
- コーラスフルーツ (CHO): 急騰と急落を繰り返す超ハイリスク銘柄。

数量はボタン操作（+/-）で直感的に調整可能です。買い増し時は取得レートが加重平均で自動計算されます。

### 3. 株式市場と配当システム (Stock Market)
架空の企業5社の株式を売買できます。

- Pupple (PPL): ハイテク首輪・デバイス企業（モチーフ: 犬）
- McMoonald (MCD): ファストフード・酪農企業（モチーフ: 牛）
- Witcha-Cola (WCC): 秘伝ポーション飲料メーカー（モチーフ: 魔女）
- Clattle (CLT): 骨格防衛・ハードウェア重工（モチーフ: スケルトン）
- EekBay (EKB): 海洋物流・オークション企業（モチーフ: イルカ）

#### 株主配当システム
各銘柄の保有評価額（株価 × 保有株数）が100E以上になると、ゲーム内日数で1日1回、各企業のモチーフに応じた配当アイテムを受け取ることができます。
- Pupple: 調理された肉各種のセット
- McMoonald: パンプキンパイ、ケーキ
- Witcha-Cola: ネザーウォート、ブレイズパウダー、きらめくスイカ等の貴重な醸造素材セット
- Clattle: 弓、矢、骨粉のセット
- EekBay: オウムガイの殻、海洋の心、プリズマリン等の海洋レアアイテム

### 4. 花の先物契約 (Flower Futures)
ウィザーローズ指数を対象とした2日満期のレバレッジ取引です。
- 証拠金5Eを支払って契約を結びます。
- 契約から2日後（ゲーム内日数）以降に満期精算を行います。
- 満期時の価格が契約基準値より高ければ利益を受け取れますが、下回っていた場合は差額損失が口座から差し引かれます。
- **債務不履行ペナルティ**: 損失が口座残高を上回ってマイナスになった場合、残高は0に没収され、激怒した警備バチがスポーンしてプレイヤーを襲撃します。

### 5. コールドウォレット (Cold Wallet)
口座内のハニカムを「物語調の取引コード（文章）」として出力し、サーバー内の掲示板やチャット、別ワールドへ手渡し・持ち出しができるオフライン資産管理機能です。

- **ウォレット作成**: 初回に自分だけの「シークレットワード（合言葉）」を設定すると、公開鍵（PK-XXXXXX）が生成されます。
- **エクスポート（出金）**: 口座のハニカムを取引コード化して出金します。「ハチと自然」「鉱石と大地」の2つのテーマから文章スタイルを選択できます。
- **コピー対応画面**: エクスポート完了時、スマートフォンやゲーム機でも長押しで「すべて選択→コピー」ができるテキストフィールド画面が表示されます。
- **直近コードの再確認**: 控える前に画面を閉じてしまっても、メニューの「直近のコードを再確認」からいつでも再表示できます。
- **インポート（受取）**: 取引コードを入力すると、記載されたハニカムが口座に反映されます。文章のままでも、単語のみの入力でも自動認識されます。
- **セキュリティ仕様**: 単調増加するNonceによるリプレイ防止（二重取り防止）、公開鍵暗号の概念を模したチェックサム署名検証を備えています。

### 6. 動物交易 (Mob Trading)
5種類の通貨はそれぞれ、動物やモブをテーマにした「動物交易」窓口も兼ねています。対応するブロック（上表参照）にインタラクトすると交易窓口が開きます。

- ハニカム: ハチ（ミツバチの巣、植木鉢不要）
- リンゴ: 馬と猫（干し草の俵 + 植木鉢）
- スイートベリー: キツネ（トウヒの原木 + 植木鉢）
- グローベリー: ウーパールーパー（苔ブロック + 植木鉢）
- コーラスフルーツ: ドラゴン・エンダーマイト・シュルカー（エンドストーンレンガ + 植木鉢）

各窓口でできること:
- **購入**: 対応する通貨を使って実際のアイテムを受け取れます。最大5品目のラインナップはゲーム内の日付ごとに入れ替わり、その日は全プレイヤーで共通です。
- **売却**: 所持アイテムを渡して通貨に換金できます。買値のおよそ60%が売却レートです。
- **レート確認**: 現在の為替レートを波形チャートと共に確認でき、他の通貨のレートも一覧で参照できます。
- **立ち去る**: なでて円満に立ち去るか、追い払うか選べます。追い払うと1ダメージのしっぺ返しがあります（ちょっとした小ネタです）。

### 7. 行商人の召喚 (Wandering Trader Summon)
白色の羊毛の真上に植木鉢を置いてインタラクトすると、その場に行商人を召喚できます。

- 自然湧きの行商人は無効化されているため、行商人と取引するにはこの方法が唯一の手段です。
- 召喚された行商人は鈍足で足止めされ、召喚地点に係留されます。押されたり殴られたりして離れても自動的に引き戻されるため、畑を踏み荒らしてどこかへ歩き去ってしまうことはありません。
- 付いてくるトレーダーラマは、召喚直後に自動的に取り除かれます。
- 既に近くに行商人がいる場合は、新規召喚の前に一掃されるので、行商人だらけになる心配もありません。

### 8. ゴーレムの現物資産取引 (Golem's Commodity Exchange)
鉄ブロックの真上に植木鉢を置いてインタラクトすると、ゴーレムを介して現物資産を電子残高（E）で直接売買できます。

- ダイヤモンド (DIA): 希少な現物資産で値動きは中程度。
- 金インゴット (AU): 伝統的に安定した資産。
- ラピスラズリ (LAP): 単価は安いものの値動きはやや荒め。

株式や外貨と異なり、現物資産は常に買値=売値の単一レートで取引されます（契約ではなく現物そのものを直接やり取りするため）。1個 / 5個 / 上限まとめ買い、1個 / 5個 / 全部売却をワンタップで行えます。

## 経済サイクルとニュース速報

市場はマインクラフト内の7日間を一区切りとする「7日サイクル」で動いています。
- 7日目が終了してDay 1に戻るタイミングで、市場の乱数シードが再設定され、新しい週の相場トレンドが始まります。
- 週替わり時には、各銘柄・為替のシード値に応じた「週刊・蜂森経済新聞（Weekly Bee News）」がチャットログに配信され、相場予測のヒントとなります。

## 言語設定 (Language)

日本語と英語（English）の完全バイリンガルに対応しています。
- プレイヤーの端末設定から初期言語が自動判定されます。
- 取引所の「言語設定」メニューから、いつでも手動で言語を切り替えることができます。
