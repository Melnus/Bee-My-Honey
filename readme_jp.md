# Bee My Honey - ハニカム電子取引所 (Bee Exchange)

Minecraft Bedrock Edition 向けの経済シミュレーション・アドオンです。ハチたちが集めた資産を元手に、外貨為替、株式、先物、現物資産の取引、融資、保険、通信販売、労働市場、そしてオフライン決済できるコールドウォレットを体験できます。

## 概要

「本」を持って巣箱(ビーハイブ)や巣(ビーネスト)を操作すると取引所が開きます。所持品のエメラルドを電子残高(E)として預け入れ、外貨・株式・先物・現物資産の取引に使います。保険、通信販売、労働市場、動物交易などのサービスは、下の表のブロックから開きます。

---

## 基本的な遊び方

### 各サービスの入り口

特に記載がない限り、メインハンドに「本(minecraft:book)」を持って、ブロックに対してインタラクト(右クリック / タップ)します。「+ 植木鉢」は、ブロックの真上に植木鉢(空でも植えてあってもよい)を置いた状態を指します。うっかりメニューを開いてしまう誤爆を防ぐための条件です。

| サービス | ブロック | 備考 |
|---|---|---|
| 取引所(メインメニュー) | 養蜂箱(ビーハイブ) | 口座・外貨・株式・先物・コールドウォレット・言語設定 |
| ハチとの交易(ハニカム窓口) | 巣(ビーネスト) | ハチと交易します |
| 現物資産取引(ゴーレム) | 鉄ブロック + 植木鉢 | ダイヤ・金・ラピスなど(下記参照) |
| 動物交易: リンゴ(APL) | 干し草の俵 + 植木鉢 | 馬と猫の窓口。**[0.4]** Paws & Blackpots もここから |
| 動物交易: スイートベリー(SWB) | トウヒの原木 + 植木鉢 | キツネの窓口 |
| 動物交易: グローベリー(GLB) | 苔ブロック + 植木鉢 | ウーパールーパーの窓口。**[0.4]** 生鮮市場もここから |
| 動物交易: コーラスフルーツ(CHO) | エンドストーンレンガ + 植木鉢 | ドラゴン・エンダーマイト・シュルカーの窓口 |
| 保険 | 骨ブロック + 植木鉢 | |
| 通信販売(Skein) | 書見台、**紙**を持つ | 植木鉢は不要 |
| 労働市場(HRMHRM Partners HLD) | 書見台、**本**を持つ | |
| 行商人の召喚 | 白い羊毛 + 植木鉢 | 自然湧きは止めてあり、この方法だけで呼べます |

## 主な機能

### 1. 口座管理 (Bank)
- 所持品のエメラルドを電子残高(E)として預け入れたり、口座から引き出したりできます。
- 取引所のすべての商品はこの電子残高で取引します。
- 引き出し時や配当の受け取り時にインベントリが満杯でも、あふれた分は足元にドロップするのでロストしません。
- 銀行画面から融資窓口へ進めます(「融資と信用スコア」参照)。

### 2. 外貨為替市場 (Forex)
価格変動の波を持つ5種類の外貨を売買できます。

- ハニカム (HNY): 基軸通貨。手堅く安定した推移。
- リンゴ (APL): 緩やかな波型を描く標準的な通貨。
- スイートベリー (SWB): 単価が安く、激しく乱高下するハイボラティリティ型。
- グローベリー (GLB): 伸びしろのある成長型。
- コーラスフルーツ (CHO): 急騰と急落を繰り返す超ハイリスク銘柄。

数量はボタン(+/-)で調整できます。買い増しのときの取得レートは加重平均で自動計算されます。

### 3. 株式市場と配当 (Stock Market)
架空の企業8社の株式を売買できます。

- Pupple (PPL): ハイテク首輪・デバイス(モチーフ: 犬)
- McMoonald (MCD): ファストフード・酪農(モチーフ: 牛)
- Witcha-Cola (WCC): 秘伝ポーション飲料(モチーフ: 魔女)
- Clattle (CLT): 骨格防衛・ハードウェア重工(モチーフ: スケルトン)
- EekBay (EKB): 海洋物流・オークション(モチーフ: イルカ)
- Skein (SKN): ジャングルのオウムが編隊配達する巨大EC企業(モチーフ: オウム)
- KelpLife Holdings (KLH): 海の生き物が運営する生命保険会社(現金配当)
- HRMHRM Partners HLD (HRM): 村人を労働者として派遣するコンサルタント(ストックオプション型配当)

#### 株主配当
各銘柄の保有評価額(株価 × 保有株数)が100E以上あると、ゲーム内日数(`world.getDay()`)で1日1回、配当を受け取れます。

- Pupple: 調理された肉のセット
- McMoonald: パンプキンパイとケーキ
- Witcha-Cola: 醸造素材(ネザーウォート、ブレイズパウダー、きらめくスイカ等)とガラス瓶
- Clattle: 弓・矢・骨粉
- EekBay: 海洋レアアイテム(オウムガイの殻、海洋の心、プリズマリンの欠片のどれか)
- Skein: サトウキビ・レッドストーン・ネザークォーツ
- KelpLife Holdings: 現金配当(残高に直接入金)
- HRMHRM: メニューからは受け取りません。労働市場で仕事が発生するたびに、ストックオプションとして自社株が付与されます。

### 4. 花の先物 (Flower Futures)
5銘柄(ローズ、アリウム、ヒスイラン、ヒマワリ、サクラ)を対象にした、2日満期の先物取引です。
- 証拠金5Eを支払って買い契約を結びます。複数ロットを持てます。
- 満期日(契約から2日後のゲーム内日数)以降に精算します。
- 精算価格が契約価格を上回れば利益、下回れば差額損失が残高から引かれます。
- **債務不履行ペナルティ:** 損失が残高を上回ると残高が0になり、警備バチが現れて襲ってきます。

### 5. 現物資産取引(ゴーレム)とバルク取引
ゴーレムと現物資産を売買します。2つのカテゴリに分かれています。

- **希少資源**(小口取引): ダイヤ、金、ラピスラズリ、**[0.4]** ネザークォーツ、レッドストーン。ダイヤ・金・ラピスのブロックは9個分として換算されます。
- **一般資源 [0.4]**(バルク取引、1回につきシュルカーボックス1箱): 丸石、鉄、銅、ガラス、原木8種類、土・砂・砂利・粘土。

バルク取引は、**設置した**シュルカーボックス(半径6ブロック以内)を使います。**買う**ときは**空の**シュルカーボックスを近くに置いておくと、そこに商品が納品されます。**売る**ときは、その品物だけで**満載**にしたシュルカーボックスを近くに置いておきます。1回の取引は1箱(1,728個)までです。

価格は週間パターンと需要圧力(後述)で動きます。バルク取引の需要圧力は、小口取引とは別々に計算されます。

### 6. 動物交易(通貨窓口)
各外貨には専用の動物窓口があります(上の表を参照)。動物が欲しがるアイテムをその通貨で売り、その通貨で動物の品物を買えます。購入した品物は足元にドロップします。

### 7. Paws & Blackpots(エネルギー取引所) **[0.4]**
リンゴ(APL)窓口(干し草の俵 + 植木鉢)から、「Paws & Blackpots」ボタンで入ります。
- **木炭・石炭・ブレイズロッド・マグマバケツ**を**APL**で、1個ずつ売買できます。
- 実在庫制で、店にある分しか買えません。木炭と石炭は毎日100個まで自動補充されます。ブレイズロッドとマグマバケツは、最初の在庫がなくなると補充されません。購入には労働市場のネザーライセンスが必要です。
- 価格は「ネコの店主の気まぐれ」で、毎日ランダムに変わります。ネコを撫でる(1日1回)、タラ・サケをあげると機嫌が上がり、最大25%まで安くなります。納品(買取)価格は、その日の言い値の60%です。

### 8. 生鮮市場 **[0.4]**
グローベリー(GLB)窓口(苔ブロック + 植木鉢)から、「生鮮市場」ボタンで入ります。
- 食べ物をプレイヤーが出品するオーダーボードで、通貨は**GLB**です。最初は空で、プレイヤーが納品すると出品が並びます。
- ジャンルは水産物・肉類・農作物・乳と卵の4つです。品目ごとに、価格推移のグラフと匿名の出品リスト(安い順)が表示されます。
- 納品するときは、いる場所の地域(沿岸・内陸・僻地)に応じて予想価格帯が示されますが、最終的な価格は自分で入力します。
- 出品された食べ物は時間とともに鮮度が落ち、残りの数量が減っていきます。完全に腐ると出品は消えます。

### 9. 食品の鮮度 **[0.4]**
**インベントリ**(オフハンド含む)にある傷みやすい食べ物は、時間がたつと腐って腐った肉に変わります。
- 生鮮物(魚・肉・牛乳・卵・未加工の農作物)はゲーム内で約**6日**、加工品(焼いた肉・パン・シチュー・ベイクドポテト・干しコンブ)は約**12日**で腐ります。
- 拾った時点からタイマーが始まります。チェスト・樽・シュルカーボックスの中では**進みません**。睡眠や時間変更でも早まりません。
- アイテムの説明文に「鮮度: ○○%」が表示され、腐る前には警告が出ます。同じ日に手に入れた食べ物は、これまで通りスタックします。
- **腐らないもの:** 砂糖、ハチミツ系、ポーション類、ケーキ、クッキー、パンプキンパイ、金のリンゴ、金のニンジン、通貨系フルーツ(リンゴ、スイートベリー、グローベリー、焼いたコーラスフルーツ)。
- 確認用コマンド(コマンド権限が必要): `/scriptevent bmh:food_info` で手持ちの食品の経過日数を表示、`/scriptevent bmh:food_age [日数]` で手持ちの食品を指定日数ぶん進めます。

### 10. 融資と信用スコア
- 融資は5段階です。高額な段階ほど、必要な信用スコアが上がり、金利も上がります。借りるのも貸すのも同時に1件までです。
- 信用スコア(300〜850)は、融資・クレジットカード・保険・破産処理で共通して使われます。
- 返済・カード請求・保険料は、週替わりのタイミングでまとめて処理されます。

### 11. 保険
海難(溺死)保険、漁獲保険、海底資産保険の3種類です。骨ブロック + 植木鉢から加入します。海難保険は溺死したとき、ほかの2つは死亡時に、契約した定額が支払われます。

### 12. 通信販売(Skein)とクレジットカード
書見台に紙を持って操作します。生鮮物・日用雑貨・機能ブロック・防具・エンチャント本・レアドロップ品のカテゴリから買い物でき、日替わり特売もあります。信用スコアに応じた限度額でクレジットカードを作り、リボ払い(契約時に固定された最低返済額)で支払えます。Prime型のサブスクリプションもあります。

### 13. 労働市場(HRMHRM Partners HLD)
書見台に本を持って操作します。
- **スタッフサービス:** 日替わりのクエスト。コンテナに納品します。
- **ライセンス:** ネザー・水中・エンドのライセンスは、その場所で対象ブロックを実際に設置・破壊した実績で取得します。
- **コンサルタントサービス:** 村人の貸与契約。
- **オーナーズクラブ:** 村人を履歴書データとして登録し、派遣します(登録は128件まで、100件を超えると事故率が上がります)。

### 14. コールドウォレット (Cold Wallet)
口座内のハニカムを、5文になった20個のキーワードの「物語調の取引コード」として出力します。掲示板やメモで共有したり、別ワールドへ持ち込んだりできます。

- **ウォレット作成:** 自分だけのシークレットワード(合言葉)を設定すると、公開鍵(PK-XXXXXX)が生成されます。
- **エクスポート(出金):** ハニカムを取引コードとして出金します。「ハチと自然」「鉱石と大地」の2つのテーマから選べます。
- **コピー対応:** 結果はテキストフィールドに表示され、どの機種でも全選択してコピーできます。
- **直近コードの再確認:** ウォレットメニューから、最後に発行したコードをいつでも再表示できます。
- **インポート(受取):** コードを貼り付けるとハニカムが口座に反映されます。句読点やつなぎの言葉は自動で無視されます。
- **セキュリティ:** 単調増加するNonceで再利用を防ぎ、公開鍵に紐づくチェックサム署名を検証します。署名に使う秘密の値はワールドごとに生成され、別ワールドへのウォレット持ち出しはオペレーター限定のオプションです。

### 15. 行商人
白い羊毛 + 植木鉢で行商人を呼び出せます。行商人は呼んだ場所につなぎ止められ(鈍足を付与し、離れたら引き戻します)、遠くへ歩いていきません。

## 経済サイクルとニュース速報

市場は、Minecraft内の7日間を一区切りとする「7日サイクル」で動いています。
- 7日目が終わってDay 1に戻るタイミングで、市場の乱数シードが再設定され、新しい週の相場が始まります。
- 週替わり時には、為替・株式のシードに応じた「週刊・蜂森経済新聞(Weekly Bee News)」がチャットに配信され、相場のヒントになります。
- **需要圧力:** 売買した量に応じて価格が動き(最大±60%)、効果は毎日少しずつ薄れていきます。為替・株式・現物資産に適用されます。

## 言語設定 (Language)

日本語と英語(English)に完全対応しています。
- プレイヤーの端末設定から、初期言語が自動判定されます。
- 取引所の「言語設定」メニューから、いつでも切り替えられます。
