# 構想メモ: ハイブシステム(2026-11-06。実装は村システムの完成後)

- バニラにはない、BMH独自の「村」の種類。蜂の巣(bee_nest / beehive)が1つでもあれば、そこを1つの村(ハイブ)として検知する。
- 小規模ハイブ(巣1つ〜): 花・砂糖など超小規模な物資のやり取り。最序盤の稼ぎにする。
- 拡大: 一定区画に巣を複数置くと拡大。蜂蜜・砂糖・染料をバルクで取引できる(工場化が大変な品なので需要が見込める)。
- 蜂は話せないので、クエスト発注(掲示板・寄り合い所)はなし。蜂の巣へのインタラクトから「お願い」を見て取引する。
- 決めること(あとで): 巣の検知範囲と「区画」の定義 / 登記(鐘のように手動か、自動検知か) / 口座・蔵の持ち方(村のコアを流用するか) / 規模の段階と各段階の品目・上限 / 染料の元(花→染料の換算を価格表で持つか) / 村・NPC会社との価格の整合 / 取引所への出荷の扱い。
- 流用できそうなもの: コアの種類(core.kind)・口座・events・取引所の出荷(shipToExchange)・地域タイプの枠組み(data/village-regions.js)。
