# 改善案(作者。2026-11-05)

実機(0.5.x)の表示で確認した4案。案1は0.6.1で実装済み。案2〜4は未実装(MILESTONES M-D)。

1. 名前の一本化(実装済み): 正典は取引リスト。追補表は data/item-names-extra.js。引くのは economy/item-names.js の itemLabel だけ。
   外部アドオンの品は economy/external-items.js(似た名前の品の値付けを借り、3日ごとに検算)。
2. 値動きの監視と反応買い: 各実体が「自分の買値上限以下の出品」を見たら、定期運行を待たずに買う。上限は1日(村は1サイクル)の必要量。方式(出品時のフック / 短い間隔の見回り)は未決。
3. 村の売買を3日サイクルに、起点は村の成立日(createdAt)から。生産量・持ち越し上限をサイクル基準に直す。クエスト注文の期限(expiresWeek)・村の決算は未決。
4. システム要因(モッド更新・長期休止)のときは、サイクル起点を現在日にリセットし、過去分のまとめ処理はしない。
