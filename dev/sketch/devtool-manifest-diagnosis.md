# 構想メモ: 開発者機能 manifest のバージョン診断(2026-11-06。時期は未定)

- 目的: サーバー/APIのバージョンが変わったときに、manifest の `@minecraft/server` などの版を上げると「どこが使えなくなるか(破壊的変更)」「何が新しく使えるか」を教える。
- 材料の案: コード中で使っているAPIの一覧(静的に抽出)× 公式の型定義(npm の @minecraft/server の各版の d.ts)の差分。manifest は自動では書き換えず、レポートだけ出す。
- 置き場所: dev/ の検査スクリプトとして(ゲーム内の機能ではなく開発者向け)。
- 備考: manifest の版(2.9.0)は公式ドキュメント上 beta 扱い。正式版は 2.7.0 までの記載(2026-11-06 時点で確認)。
