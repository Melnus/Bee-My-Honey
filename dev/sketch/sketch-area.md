## 決定事項(作者の方針)
- 領域の種類は**2つだけ**: **プライベートスペース**(個人)と**会社の敷地**。村の領域などは作らない。
- プライベートスペース = **自分の本棚を中心にした、自分で決める範囲**。登録の流れ(2026-11-02):
  1. 本棚を**紙で触る**(申請。書見台は、紙・本で取引所・労働市場の入口に使っているので、本棚にした)。
  2. **木の棒で、範囲の対角の2点をクリック**する。その2点でできる長方形が、範囲として登録される。
  3. **場所代**が取られる(面積に応じて)。会社の敷地 = 会社のロードストーン(コアブロック)の周りNブロック。

## 参考(Fairy Garden Estate のしくみ)
- 領域 = 中心の座標 + 半径(正方形、XZ。区画は3/5/7マス)。重なりをチェックして登録、取り壊しもある。
- モブの追い出し: 敵対モブは領域の外周+余白に入ったら消す。友好・中立のモブは、許可リストに無ければ境界の外へテレポートで押し出す。一定間隔の見回りで処理する。
- **プレイヤーは対象外**。スクリプトでは、プレイヤーが入るのを止められない。

## 案(未確定。検討のたたき台)

### 1. 何を守るか
- **操作の保護(中心)**: 領域内で、持ち主(会社ならメンバー)以外が、壊す・置く・箱やシュルカーなどを開く操作を止める。コアブロック(`core-guard.js`)・専用シュルカー(`private-shulker-guard.js`)と同じイベントを使う。
- **モブ**: FGEの追い出しを使う。敵対モブは消し、持ち主・メンバー以外のテイム済みでないモブは境界の外へ。見回りは長めの間隔にして、領域ごとに検索範囲を小さくする。
- **プレイヤー**: 入るのは止めない。押し戻し・ゲームモードの変更は、操作感と実装の可否(未確認)から、入れない。
- 高さ(Y)は制限しない(領域は柱状。地下からの侵入も操作の保護で止まる)。

### 2. プライベートスペース(個人)
- 登録: 自分の本棚(`minecraft:bookshelf`。装飾本棚 `chiseled_bookshelf` とは別)を、紙で触る。既存の入口(書見台+紙/本、本+ブロック)とぶつからない。登録した本棚は、壊せない(解除してから壊す)。
- 1人1つ。解除・移動は、同じメニューから(専用シュルカーと同じ)。ほかの人の領域・村・会社の敷地と重なる位置は登録できない。
- 範囲は長方形(XZ)。2点の高さは問わず、高さ(Y)は全部を守る。範囲の大きさ(1辺・面積)の上限は未決。本棚が範囲の中にあることを条件にする(案)。
- 申請の途中: 1点目をクリックしたら、2点目を待つ(時間切れ・別の操作で取り消し)。2点目で、範囲と場所代を確認する画面を出し、了承したら、場所代を払って登録する(払えなければ登録しない)。
- 書見台は入口として独立なので、領域内でも、だれでも紙・本で触って取引所・労働市場を開ける(領域の保護の対象は、壊す・置く・箱を開く操作だけ)。
- 持ち主が長期不在なら、専用シュルカーと同じ考え方で解除する(不在日数は別の設定値)。

### 3. 会社の敷地
- 会社もプライベートと同じ流れ(案): 会社のロードストーン(登記済み)を触って申請 → 木の棒で対角の2点 → 場所代。メンバーは `core.members` を許可リストにそのまま使う。
- 会社を解散したら、敷地も消える。

### 4. 費用と制限(領域の取り合いと荒らし対策)
- **場所代**(決定: 取る。単価は **ベース20E/マス**。2026-11-02): 物価レベルを掛けるので、インフレに合わせて上がる(×64の今は1,280E/マス。1マス=1日分の基準賃金 `OWNER_BASE_WAGE_PER_DAY`)。面積 × 単価。例: 8×8 = 81,920E、16×16 = 327,680E、32×32 = 1,310,720E(会社の登録料より高い)。取った分は、HRMHRMの収入(新しい台帳のカテゴリ。送金の手数料と同じ扱い)。**支払いは3週ごと**(決定。2026-11-02。現実の月払いに合わせる)。**維持費はベース0.15E/マス(3週ごと)**(2026-11-03。×64の今は9.6E/マス)。登録の時に、**+15%の割り増し(ベース3E/マス)を払えば、維持費は永久に要らない**(買い切り)。例: 8×8 = 登録81,920E + 維持費614E/3週、買い切りは94,208E。16×16 = 登録327,680E + 2,458E/3週、買い切りは376,832E。32×32 = 登録1,310,720E + 9,830E/3週、買い切りは1,507,328E。損益分岐は20回(60週)。払えない時は、1回分の猶予のあと、領域が解除される(案)。買い切りの領域を解除・移動しても、返金はしない(案)。
- 大きさの上限、1人1つ。他の領域との重なり禁止。村(鐘)の近くへの登録制限は未決。
