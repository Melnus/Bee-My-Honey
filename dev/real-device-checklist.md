# 実機確認チェックリスト(法人テンプレートの前に、2026-10-05)

0.4.3(`Bee-My-Honey-043.zip`。旧 `dev/archive/wage-revision/` を0.4.2配布版に重ねたもの)を、実機のBedrockで一度通すための手順。
**ワールドのバックアップを先に取ること**(既存ワールドへの導入では、初回ログイン時に金額が1回だけ換算され、元に戻せない)。

## 0. 配布物
`Bee-My-Honey-043.zip` は、0.4.2の配布版にこの変更を適用しただけのもの。**manifest.json は0.4.2のまま**(version / name の更新は作者が行う)。
実機で差し替える時は、manifestのバージョンを上げておかないと、古いパックのキャッシュが使われることがある。

## 0.5 用意するワールド
- **A: 旧ワールド** — 0.4.2で遊んでいる(または作った)ワールドのコピー。口座残高・借入・カード・外貨/株/先物の保有・派遣契約のどれかが入っているもの。
- **B: 新規ワールド** — 何も入っていない、新版だけで始めるワールド。

## 1. 導入前に控えておく(Aのみ)
口座残高 / 借入残高・週の返済額 / カードの限度額・残高・最低返済 / 外貨・株・先物の保有と取得価格 / 進行中の派遣契約のマージン。

## 2. 導入と換算(A)
1. パックを差し替えてワールドを開く(043の配布物をそのまま入れる。重ね適用は不要)。
2. ログインした時に「[経済更新] … ×64 に換算しました」が**1回だけ**出る。
3. 控えた金額が64倍になっている(外貨の単位数・株の枚数は変わらない)。
4. いったん抜けて入り直しても、再換算されない。
5. B では、換算メッセージが出ず、金額が変わらない。

## 3. 管理コマンド(オペレーター)
- `/scriptevent bmh:pricelevel` → `x64 * index 1` の表示。`/scriptevent bmh:pricelevel 2` で指数を2にして、画面の価格が約2倍になること(確認後は `1` に戻す)。
- `/scriptevent bmh:ledger 1` → 発行台帳の集計(in / out / 純増)。
- `/scriptevent bmh:devbank` → 開発銀行機構の判断の履歴(審査件数・支給の累計・売却させた資産の代金)。
- `/scriptevent bmh:account` → HRMHRMの貸借対照表(末尾に開発銀行の要約も出る)(現金・債権・現物・貴金属の割合・直近の週の損益)。`/scriptevent bmh:account list` で口座の一覧(いまはhrmhrmだけ)。
- `/scriptevent bmh:policy list` → 政策パラメータの一覧。`set policy_rate 0.0009` で預金金利が変わる(銀行画面の週利表示)。`reset all` で戻す。

## 13. 法人テンプレート(鐘=村 / ロードストーン=会社)
準備: 口座に 100万E 以上と、輝くイカスミ(`/give @s glow_ink_sac 5`)。
- **会社の登記**: ロードストーンを置き、イカスミを持って触る → 会社名を入力。
  - 登録料(約100万E)が引かれ、入出金履歴に「HRMHRMへ」と残る。イカスミが1個減る。管理メニューが開く。
  - 残高が足りないとき: 「登録料が足りません」と出て、イカスミも残高も減らない。
  - 名前: 空・11文字以上・「HRMHRM」を含む名前・既存の会社と同じ名前は弾かれる。2社目は「1人1社」で弾かれる。
- **村の登記**: 鐘を置き、イカスミを持って触る → 登記する。無料。村名・村長がランダムで決まる。64ブロック以内に別の鐘で登記しようとすると弾かれる。
- **固定**: 登記済みのブロックを壊そうとする(クリエイティブでも)→ 壊れず、メッセージが出る。TNT・クリーパーの爆発で残る。`/setblock ~ ~ ~ air` で消すと、約10秒で元に戻る(鐘の向きも)。
- **人員管理(会社)**: 別アカウントで触る → 「応募する」。社長側で「応募者を確認」→ 採用 / 見送り。メンバー側は「退職する」。
  - 1人で試す: `/scriptevent bmh:core fakeapply テスト` で偽の応募者を作る。`/scriptevent bmh:core absent` で社長が不在の扱いにして、メンバー役の別アカウントで採用できること(会計などは触れないこと)。`present` で戻す。
- **人員管理(村)**: 村人を囲っておいて触る → 人数(大人/子供)。日が変わって近くにいると履歴に記録される。
- **解散**: 経営管理 → 解散手続き。見積もり(現金・買取・負債・結果、ペナルティ)を確認 → 解散する。
  - 登記が消え、ブロックが壊せるようになる。信用スコアが20%下がり、14日間は新しい会社を登記できない(`bmh:policy` の `dissolve_cooldown_days` を0にして再試験できる)。
  - `/scriptevent bmh:core list` に「dissolved」で墓標が出る。`/scriptevent bmh:account list` から口座が消える。
- **自動解散**(確認は設定値を下げて): `/scriptevent bmh:policy set company_absent_days 7 force` で最短にし、メンバーのいない会社の社長が7日不在 → 強制解散。社長がオフラインなら、次のログインで清算金と信用の減点がメッセージで出る。
- **未確認のまま残るもの**: 会計管理・保有施設・在庫管理・契約管理は「準備中」と出るだけ。
- **仮想施設・在庫・契約**: 会社を作る → オーナーズクラブで村人を登録 → 派遣する → ジャンル(農場など)を選ぶと、運営主体に「HRMHRM」と並んで自分の会社が出る → 日数を選ぶ。
  - 会社の「契約管理」に進行中の派遣(相手・ジャンル・あと何日・産出予定)が出る。期日後に回収すると、「在庫管理」に産出が入り、契約の「最近の結果」に「入荷」が残る。
  - 在庫が保持数(既定640)を超えた状態で1週間進める → 会社の「会計管理」の直近の週に収益(換金)が出る。`/scriptevent bmh:policy set pool_keep_per_item 0 force` で保持数を下げると試しやすい。
  - 派遣中に社長が会社を解散 → 村人を回収すると「施設は閉鎖されていた」と出て、産出は届かない。在庫は `bmh:account` のプールに移る。
  - 村の管理メニューでは、在庫管理・契約管理は「会社だけが使えます」と出る。会計管理は村でも開く。

## 13b. 村の入荷(村からのクエスト)・工場の加工
準備: 鐘を登記した村(住民を囲って人口を記録)。村の口座に資金が要る(週を進めると開発銀行機構から最低運用資金が入る)。
- スタッフサービス → 村からのクエスト: 近い村の一覧(受けられる依頼の数・村の空き資金)→ 村を選ぶと今日の3品目が「受注済み 0/必要数」と「今 ○個まで受けられます」で出る。人口0の村は出ない。新しい村は、最初の週の締めに開発銀行機構から運用資金が入るまで資金が0(「資金が足りず受けられません」と出る)。
- 村の依頼は人ごと・日ごとに違う(別アカウントで同じ村を開くと、品目か量が違う)。自分の分を受けきると「きょうの分は受注済み」で止まるが、他の人の分には影響しない。
- 品目を選ぶ → 数量(上限 = 枠の残り と 村の資金)を入れて受注。受注中の注文が先頭に[受注中]で出る。
- 書見台の近くのチェストに品物を入れて「納品する」→ 村の口座から代金が入る。放棄すると枠が戻る。
- 枠が埋まった品は「村の倉庫はいっぱい」と出て受けられない(別の村へは行ける)。同じ品は同じ日に1人1回。
- 週を進める: 村の在庫が加工され、出荷品が売れて村の口座に入る(管理メニューの会計で確認)。
- 工場への派遣: 在庫に原料がない工場は「原料の在庫がありません」と出て派遣できない。農場・鉱山からの産出が入ると動く。
- 村の管理メニュー: 在庫管理(村の在庫と先週の加工・出荷)・契約管理(きょうの必要数と受注の一覧、村の資金)が村でも開く。会社の契約管理にも自動依頼が出る。品名は日本語で出る。
- **会社からのクエスト**: 会社を作る(口座に資金が要る。`/scriptevent bmh:account` で確認)→ スタッフサービス → 会社からのクエスト: 金の原石(32)・ダイヤ(8)・糸(128)の不足分が「受注済み/必要数」で出る。納品すると会社の在庫が増え、目標に達すると依頼が消える。会社の資金が足りないと受けられない。
- 会社の工場へ派遣: 金の原石が在庫にあれば、金インゴットが産出される(原石がなければ「原料の在庫がありません」)。
- (HRMHRMの金・ダイヤ供給に追加の上限は設けない)

## 14b. 借入依頼・送金・村の解散(0.5.3)
- 「借りる」→「貸し手を募集する」: 金額を選ぶと依頼が出る。同時に1件。「募集を取り下げる」で消える。借入のメニューに募集中の表示(あと約◯日)が出る。
- 別のプレイヤーの「貸す」に、その依頼が「[個人] 名前 - …」で並ぶ。選ぶと貸し手から引かれ、借り手に入る。借り手がオフラインの依頼は並ばない。
- 週の締めで、借り手の返済が貸し手に届く。貸し手がオフラインなら、次にログインした時に届く。完済すると貸し手の「融資管理」の貸付が消える。
- 資金が少ない村・会社(鐘/ロードストーンの近くで日が変わる頃)が「[村]/[会社] 名前 - …」の依頼を出す。引き受けると村/会社の口座に入り、毎週返済される。
- 依頼が7日以上たって消えても、現金が運用の下限を割ったままなら、会社・村は強制解散になる(通常は開発銀行機構の支給があるのでまず起きない)。
- 村を解散すると、代表者には払われず、残りの現金がHRMHRMへ戻る。借りているローンがあれば、先に貸し手へ返る。
- 銀行→「送金する」: オンラインの相手を選び、数量を決めて確認すると届く。相手には「◯◯から◯◯Eが届きました」と出る。入出金履歴に残る。
- 資産の上限: 口座が少ないと「借りる→貸し手を募集」で段が出ない(上限の案内が出る)。口座を増やすと出せる段が増える(純資産の半分まで)。貸す側も、資産の半分を超える依頼は「貸せる額を超えています」で断られる。
- 個人間ローンを完済しても、信用スコアは上がらない(銀行のローンは従来どおり上がる)。
- 借り手が来なくなったままの貸付は、期間+4週を過ぎると、貸し手のログイン時か「貸す」「融資管理」を開いた時に貸し倒れで閉じる。
- 村・会社: 在庫が溜まっているのに資金が足りない時は、依頼を出さずに在庫が売られて現金になる(会社の在庫・村の在庫が減る)。
- 送金: 確認画面に手数料が出る。1日の上限を超えると「今日の送金上限を超えます」。日が変わると戻る。

## 14c. 日英の名前・改名・長期不在(0.5.3)
- 村を新しく作る(鐘)と、日本語の言語設定では日本語の村名と村長名、英語設定では英語の村名と村長名が出る。管理メニュー・掲示板・メッセージのどれも、閲覧者の言語に合っている。
- 会社の登録フォーム: 1つ目が自分の言語の名前、2つ目が「もう一方の言語の名前(任意)」。2つ目を空にすると、どちらの言語でも同じ名前が出る。日本語名・英語名のどちらかが既存の会社と同じだと断られる。
- 従業員(村人)の名前が、英語設定では英語名で出る。
- 0.5.2 以前から有る村(英語名なし)も、英語設定で英語の名前が出る。
- 村の注文を受けたあとにゲーマータグを変えても、そのまま納品できる(掲示板の「受注者」の表示は古い名前のままでも問題ない)。
- 戻らない貸し手(長期不在)の返済は、ログインした時にまとめて届く。借り手が来なくなった貸付は、期間+4週を過ぎると貸し倒れで閉じる。
