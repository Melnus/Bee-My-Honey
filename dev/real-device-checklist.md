# 実機確認チェックリスト(法人テンプレートの前に、2026-10-05)

0.4.3(`Bee-My-Honey-043.zip`。旧 `dev/archive/wage-revision/` を0.4.2配布版に重ねたもの)を、実機のBedrockで一度通すための手順。
**ワールドのバックアップを先に取ること**(既存ワールドへの導入では、初回ログイン時に金額が1回だけ換算され、元に戻せない)。

## 0. 配布物
`Bee-My-Honey-043.zip` は、0.4.2の配布版にこの変更を適用しただけのもの。**manifest.json は0.4.2のまま**(version / name の更新は作者が行う)。
実機で差し替える時は、manifestのバージョンを上げておかないと、古いパックのキャッシュが使われることがある。

## 0.5 用意するワールド
- **A: 旧ワールド** — 0.4.2で遊んでいる(または作った)ワールドのコピー。口座残高・借入・カード・外貨/株/先物の保有・派遣契約のどれかが入っているもの。
- **B: 新規ワールド** — 何も入っていない、新版だけで始めるワールド。

## 1. 導入前に控えておく(Aのみ)
口座残高 / 借入残高・週の返済額 / カードの限度額・残高・最低返済 / 外貨・株・先物の保有と取得価格 / 進行中の派遣契約のマージン。

## 2. 導入と換算(A)
1. パックを差し替えてワールドを開く(043の配布物をそのまま入れる。重ね適用は不要)。
2. ログインした時に「[経済更新] … ×64 に換算しました」が**1回だけ**出る。
3. 控えた金額が64倍になっている(外貨の単位数・株の枚数は変わらない)。
4. いったん抜けて入り直しても、再換算されない。
5. B では、換算メッセージが出ず、金額が変わらない。

## 3. 管理コマンド(オペレーター)
- `/scriptevent bmh:pricelevel` → `x64 * index 1` の表示。`/scriptevent bmh:pricelevel 2` で指数を2にして、画面の価格が約2倍になること(確認後は `1` に戻す)。
- `/scriptevent bmh:ledger 1` → 発行台帳の集計(in / out / 純増)。
- `/scriptevent bmh:devbank` → 開発銀行機構の判断の履歴(審査件数・支給の累計・売却させた資産の代金)。
- `/scriptevent bmh:account` → HRMHRMの貸借対照表(末尾に開発銀行の要約も出る)(現金・債権・現物・貴金属の割合・直近の週の損益)。`/scriptevent bmh:account list` で口座の一覧(いまはhrmhrmだけ)。
- `/scriptevent bmh:policy list` → 政策パラメータの一覧。`set policy_rate 0.0009` で預金金利が変わる(銀行画面の週利表示)。`reset all` で戻す。

## 5. 週をまたぐ確認
ベッドで寝るなどしてワールドの日付を進め、1週間が終わった時に:
- 預金の利息が入る・融資の返済/カードの請求/保険料が引き落とされる(エラーが出ない)。
- インフレ指数が動く(活動があった週だけ。`/scriptevent bmh:pricelevel` で確認。1週で最大0.05%なので、ほぼ1のまま)。
- HRMHRMの週次の締めが走る(`/scriptevent bmh:account` の「processed week」が進む。直近の週の収益・費用に、その週のプレイヤーの動きが出る)。
- ログ(コンテンツログ)に `[BeeMyHoney]` の警告やエラーが出ていない。

## 6. 既知の注意
- 導入した日のクエスト掲示板に旧金額のものが残っていれば、その日だけ報酬が低い。
- ゴーレムの数量入力は今回置き換えていない(別方式)。
- 動物交易・PB・生鮮市場の外貨は、これまでどおり「無から出る」扱い(台帳に載らない)。

# 0.4.5 の追加確認(ローン・銀行履歴・クエスト・派遣・プール)

0.4.3 の確認(上)が済んでから。0.4.5 は、0.4.3 の上に `scripts/` を重ねたもの。**manifest.json は0.4.3のまま**(version / name の更新は作者が行う)。
先に `node dev/check_labor.mjs scripts` / `check_loan.mjs` / `check_hrmhrm.mjs` / `check_policy.mjs` / `check_ledger.mjs` が通ることを確認する(ゲーム外の検算)。

## 7. ローン(銀行 → ローン窓口 → 融資管理)
- 借入がある状態で「融資管理」を開く: 残高・元本・利息・週額・残り週が出る。貸付があれば相手・元本・残り週も出る。
- 「返済する」→ トグルOFF: 借りた分だけ引かれ、残りは利息だけになる(週額が下がる)。ON: 全額引かれて完済し、ローンなしになる。
- 現金が足りない時は、不足額のメッセージが出て、何も引かれない。
- **既存ワールドの既存ローン**(0.4.3 以前に組んだもの)は元本の記録が無く、「元本のみ」でも全額返済になる(仕様)。次の借入から分かれる。

## 8. 銀行の入出金履歴(銀行 → 入出金履歴)
- 入金・出金・利息・クエスト報酬のあとに開く: 新しい順に、日・額・理由が出る。クエスト報酬・派遣マージン・雇用ボーナスには「(HRMHRM Partners HLDから)」が付く。
- 預金利息は、同じ週で1行にまとまる。30件を超えると古いものから消える。

## 9. クエスト(書見台 → スタッフサービス)
- 【初回の仕事は2026-10-09 に実機確認済み】
- **新しいプレイヤー(または実績がないプレイヤー)で初めて開く**: 一覧の先頭に「[初回] 初めてのアルバイト」が出る。選ぶと使い方の説明 → 「報告する」でシュルカーボックスが1個もらえる(持ち物がいっぱいなら足元に落ちる)。もう一度開くと出ない。実績があるプレイヤー(あなたの既存ワールド)には出ない。
  - もらえるシュルカーのIDは、通販の `minecraft:shulker_box`。渡せない環境では無染色のIDに切り替わる。**どちらでも渡せなければ「渡せませんでした」と出て、印は付かない**(その場合はIDを直す)。
- 掲示は4件(資格なし / ネザー / 水中 / エンド)。ライセンスが無いものは「[資格が必要]」で、選ぶと案内画面になる。
- 選ぶと詳細(受注する)。受注 → 「[受注中]」で一覧の先頭に出る。もう一度選ぶと「納品する / 放棄する」。
- 同時に受けられるのは2件まで(`/scriptevent bmh:policy set quest_max_active 3` で変更できる)。3件目は拒否される。
- 別のプレイヤーが同じクエストを受けると、詳細の「受注中の人」に名前が出る。放棄すると外れる。
- 日が変わって掲示が入れ替わっても、受注中のクエストは一覧に残り、納品できる。週が変わると消える(期限切れ)。
- 納品: 書見台の近くの集荷箱から必要数が消え、口座に報酬が入る。同じクエストを2回納品できない。

## 10. 派遣(オーナーズクラブ → 履歴書を見る → 村人 → 派遣する)
- 村人を選ぶと「派遣する」。ジャンル(農場 / 鉱山 / 工場)→ 日数(3日/7日)の順(いまは運営主体がHRMHRMだけなので、運営主体の選択は自動で飛ぶ)。
- 派遣すると「産出予定: ○○ x個」が出る。期日になったら村人を選んで回収 → マージンが入り、「施設に ○○ x個が届きました」が出る(事故の時は届かない)。
- 村人の詳細に「通算派遣日数: x/1095日」が出る。上限に達した回収で「任期満了で除名」になり、一覧から消える(テストするなら `/scriptevent bmh:policy set resume_tenure_days 365 force` などで下げる)。
- `/scriptevent bmh:account` の末尾に「プール: 品目 個数, …」が出る。

## 11. プールの換金(週をまたぐ確認)【2026-10-09 確認済み】
- プールの品目が保持数(既定640個)を超えた状態で1週間進める: HRMHRMの直近の週の収益に換金が入り、プールが保持数まで減る(`bmh:account` で確認。`pool_keep_per_item` / `pool_sale_ratio` で変更できる)。
