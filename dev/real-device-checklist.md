# 実機確認チェックリスト(法人テンプレートの前に、2026-10-05)

0.4.3(`Bee-My-Honey-043.zip`。旧 `dev/archive/wage-revision/` を0.4.2配布版に重ねたもの)を、実機のBedrockで一度通すための手順。
**ワールドのバックアップを先に取ること**(既存ワールドへの導入では、初回ログイン時に金額が1回だけ換算され、元に戻せない)。

## 0. 配布物
`Bee-My-Honey-043.zip` は、0.4.2の配布版にこの変更を適用しただけのもの。**manifest.json は0.4.2のまま**(version / name の更新は作者が行う)。
実機で差し替える時は、manifestのバージョンを上げておかないと、古いパックのキャッシュが使われることがある。

## 0.5 用意するワールド
- **A: 旧ワールド** — 0.4.2で遊んでいる(または作った)ワールドのコピー。口座残高・借入・カード・外貨/株/先物の保有・派遣契約のどれかが入っているもの。
- **B: 新規ワールド** — 何も入っていない、新版だけで始めるワールド。

## 1. 導入前に控えておく(Aのみ)
口座残高 / 借入残高・週の返済額 / カードの限度額・残高・最低返済 / 外貨・株・先物の保有と取得価格 / 進行中の派遣契約のマージン。

## 2. 導入と換算(A)
1. パックを差し替えてワールドを開く(043の配布物をそのまま入れる。重ね適用は不要)。
2. ログインした時に「[経済更新] … ×64 に換算しました」が**1回だけ**出る。
3. 控えた金額が64倍になっている(外貨の単位数・株の枚数は変わらない)。
4. いったん抜けて入り直しても、再換算されない。
5. B では、換算メッセージが出ず、金額が変わらない。

## 3. 管理コマンド(オペレーター)
- `/scriptevent bmh:pricelevel` → `x64 * index 1` の表示。`/scriptevent bmh:pricelevel 2` で指数を2にして、画面の価格が約2倍になること(確認後は `1` に戻す)。
- `/scriptevent bmh:ledger 1` → 発行台帳の集計(in / out / 純増)。
- `/scriptevent bmh:devbank` → 開発銀行機構の判断の履歴(審査件数・支給の累計・売却させた資産の代金)。
- `/scriptevent bmh:account` → HRMHRMの貸借対照表(末尾に開発銀行の要約も出る)(現金・債権・現物・貴金属の割合・直近の週の損益)。`/scriptevent bmh:account list` で口座の一覧(いまはhrmhrmだけ)。
- `/scriptevent bmh:policy list` → 政策パラメータの一覧。`set policy_rate 0.0009` で預金金利が変わる(銀行画面の週利表示)。`reset all` で戻す。

## 9. クエスト(書見台 → スタッフサービス)

## 13. 法人テンプレート(鐘=村 / ロードストーン=会社)
準備: 口座に 100万E 以上と、輝くイカスミ(`/give @s glow_ink_sac 5`)。
- **会社の登記**: ロードストーンを置き、イカスミを持って触る → 会社名を入力。
  - 登録料(約100万E)が引かれ、入出金履歴に「HRMHRMへ」と残る。イカスミが1個減る。管理メニューが開く。
  - 残高が足りないとき: 「登録料が足りません」と出て、イカスミも残高も減らない。
  - 名前: 空・11文字以上・「HRMHRM」を含む名前・既存の会社と同じ名前は弾かれる。2社目は「1人1社」で弾かれる。
- **村の登記**: 鐘を置き、イカスミを持って触る → 登記する。無料。村名・村長がランダムで決まる。64ブロック以内に別の鐘で登記しようとすると弾かれる。
- **固定**: 登記済みのブロックを壊そうとする(クリエイティブでも)→ 壊れず、メッセージが出る。TNT・クリーパーの爆発で残る。`/setblock ~ ~ ~ air` で消すと、約10秒で元に戻る(鐘の向きも)。
- **人員管理(会社)**: 別アカウントで触る → 「応募する」。社長側で「応募者を確認」→ 採用 / 見送り。メンバー側は「退職する」。
  - 1人で試す: `/scriptevent bmh:core fakeapply テスト` で偽の応募者を作る。`/scriptevent bmh:core absent` で社長が不在の扱いにして、メンバー役の別アカウントで採用できること(会計などは触れないこと)。`present` で戻す。
- **人員管理(村)**: 村人を囲っておいて触る → 人数(大人/子供)。日が変わって近くにいると履歴に記録される。
- **解散**: 経営管理 → 解散手続き。見積もり(現金・買取・負債・結果、ペナルティ)を確認 → 解散する。
  - 登記が消え、ブロックが壊せるようになる。信用スコアが20%下がり、14日間は新しい会社を登記できない(`bmh:policy` の `dissolve_cooldown_days` を0にして再試験できる)。
  - `/scriptevent bmh:core list` に「dissolved」で墓標が出る。`/scriptevent bmh:account list` から口座が消える。
- **自動解散**(確認は設定値を下げて): `/scriptevent bmh:policy set company_absent_days 7 force` で最短にし、メンバーのいない会社の社長が7日不在 → 強制解散。社長がオフラインなら、次のログインで清算金と信用の減点がメッセージで出る。
- **未確認のまま残るもの**: 会計管理・保有施設・在庫管理・契約管理は「準備中」と出るだけ。
- **仮想施設・在庫・契約**: 会社を作る → オーナーズクラブで村人を登録 → 派遣する → ジャンル(農場など)を選ぶと、運営主体に「HRMHRM」と並んで自分の会社が出る → 日数を選ぶ。
  - 会社の「契約管理」に進行中の派遣(相手・ジャンル・あと何日・産出予定)が出る。期日後に回収すると、「在庫管理」に産出が入り、契約の「最近の結果」に「入荷」が残る。
  - 在庫が保持数(既定640)を超えた状態で1週間進める → 会社の「会計管理」の直近の週に収益(換金)が出る。`/scriptevent bmh:policy set pool_keep_per_item 0 force` で保持数を下げると試しやすい。
  - 派遣中に社長が会社を解散 → 村人を回収すると「施設は閉鎖されていた」と出て、産出は届かない。在庫は `bmh:account` のプールに移る。
  - 村の管理メニューでは、在庫管理・契約管理は「会社だけが使えます」と出る。会計管理は村でも開く。

## 13b. 村の入荷(村からのクエスト)・工場の加工
準備: 鐘を登記した村(住民を囲って人口を記録)。村の口座に資金が要る(週を進めると開発銀行機構から最低運用資金が入る)。
- スタッフサービス → 村からのクエスト: 近い村の一覧(受けられる依頼の数・村の空き資金)→ 村を選ぶと今日の3品目が「受注済み 0/必要数」と「今 ○個まで受けられます」で出る。人口0の村は出ない。新しい村は、最初の週の締めに開発銀行機構から運用資金が入るまで資金が0(「資金が足りず受けられません」と出る)。
- 村の依頼は人ごと・日ごとに違う(別アカウントで同じ村を開くと、品目か量が違う)。自分の分を受けきると「きょうの分は受注済み」で止まるが、他の人の分には影響しない。
- 品目を選ぶ → 数量(上限 = 枠の残り と 村の資金)を入れて受注。受注中の注文が先頭に[受注中]で出る。
- 書見台の近くのチェストに品物を入れて「納品する」→ 村の口座から代金が入る。放棄すると枠が戻る。
- 枠が埋まった品は「村の倉庫はいっぱい」と出て受けられない(別の村へは行ける)。同じ品は同じ日に1人1回。
- 週を進める: 村の在庫のうち、消費されない原料(苗木・棒・羽根・羊毛・鉄/銅の原石・木炭)だけが出荷されて村の口座に入る。食料・骨粉・腐った肉は消費される。パンやインゴットには加工されない(管理メニューの在庫管理で確認)。
- 工場への派遣: 在庫に原料がない工場は「原料の在庫がありません」と出て派遣できない。農場・鉱山からの産出が入ると動く。
- 村の管理メニュー: 在庫管理(村の在庫と先週の加工・出荷)・契約管理(きょうの必要数と受注の一覧、村の資金)が村でも開く。会社の契約管理にも自動依頼が出る。品名は日本語で出る。
- **会社からのクエスト**: 会社を作る(口座に資金が要る。`/scriptevent bmh:account` で確認)→ スタッフサービス → 会社からのクエスト: 金の原石(32)・ダイヤ(8)・糸(128)の不足分が「受注済み/必要数」で出る。納品すると会社の在庫が増え、目標に達すると依頼が消える。会社の資金が足りないと受けられない。
- 会社の工場へ派遣: 金の原石が在庫にあれば、金インゴットが産出される(原石がなければ「原料の在庫がありません」)。
- (HRMHRMの金・ダイヤ供給に追加の上限は設けない)

- **新しいプレイヤー**で書見台 + 本 → スタッフサービス: 1行目に「導入クエスト (0/4)」、続けて「資格なしの求人」「資格が必要な求人」「村からのクエスト」「会社からのクエスト」が並ぶ。

## 14b. 借入依頼・送金・村の解散(0.5.3)
- 「借りる」→「貸し手を募集する」: 金額を選ぶと依頼が出る。同時に1件。「募集を取り下げる」で消える。借入のメニューに募集中の表示(あと約◯日)が出る。
- 別のプレイヤーの「貸す」に、その依頼が「[個人] 名前 - …」で並ぶ。選ぶと貸し手から引かれ、借り手に入る。借り手がオフラインの依頼は並ばない。
- 週の締めで、借り手の返済が貸し手に届く。貸し手がオフラインなら、次にログインした時に届く。完済すると貸し手の「融資管理」の貸付が消える。
- 資金が少ない村・会社(鐘/ロードストーンの近くで日が変わる頃)が「[村]/[会社] 名前 - …」の依頼を出す。引き受けると村/会社の口座に入り、毎週返済される。
- 依頼が7日以上たって消えても、現金が運用の下限を割ったままなら、会社・村は強制解散になる(通常は開発銀行機構の支給があるのでまず起きない)。
- 村を解散すると、代表者には払われず、残りの現金がHRMHRMへ戻る。借りているローンがあれば、先に貸し手へ返る。
- 銀行→「送金する」: オンラインの相手を選び、数量を決めて確認すると届く。相手には「◯◯から◯◯Eが届きました」と出る。入出金履歴に残る。
- 資産の上限: 口座が少ないと「借りる→貸し手を募集」で段が出ない(上限の案内が出る)。口座を増やすと出せる段が増える(純資産の半分まで)。貸す側も、資産の半分を超える依頼は「貸せる額を超えています」で断られる。
- 個人間ローンを完済しても、信用スコアは上がらない(銀行のローンは従来どおり上がる)。
- 借り手が来なくなったままの貸付は、期間+4週を過ぎると、貸し手のログイン時か「貸す」「融資管理」を開いた時に貸し倒れで閉じる。
- 村・会社: 在庫が溜まっているのに資金が足りない時は、依頼を出さずに在庫が売られて現金になる(会社の在庫・村の在庫が減る)。
- 送金: 確認画面に手数料が出る。1日の上限を超えると「今日の送金上限を超えます」。日が変わると戻る。

## 14c. 日英の名前・改名・長期不在(0.5.3)
- 村を新しく作る(鐘)と、日本語の言語設定では日本語の村名と村長名、英語設定では英語の村名と村長名が出る。管理メニュー・掲示板・メッセージのどれも、閲覧者の言語に合っている。
- 会社の登録フォーム: 1つ目が自分の言語の名前、2つ目が「もう一方の言語の名前(任意)」。2つ目を空にすると、どちらの言語でも同じ名前が出る。日本語名・英語名のどちらかが既存の会社と同じだと断られる。
- 従業員(村人)の名前が、英語設定では英語名で出る。
- 0.5.2 以前から有る村(英語名なし)も、英語設定で英語の名前が出る。
- 村の注文を受けたあとにゲーマータグを変えても、そのまま納品できる(掲示板の「受注者」の表示は古い名前のままでも問題ない)。
- 戻らない貸し手(長期不在)の返済は、ログインした時にまとめて届く。借り手が来なくなった貸付は、期間+4週を過ぎると貸し倒れで閉じる。

## 15. 専用シュルカー(0.5.5)
- 本でシュルカーボックス(置いたもの)を触る → 「専用シュルカー」のメニュー(登録する / 閉じる)。染色したもの・染色なしのどちらも登録できる。
- 登録後、持ち主は普通に開ける。別アカウントが触ると「○○さんの専用シュルカーです。開けません。」で開かない。
- 登録したシュルカーは、持ち主も他人も壊せない(「本で触って、登録を解除してから壊してください」)。TNT・クリーパーの爆発で壊れない。
- 本で触ると、解除のメニューが出る(空きスロットの表示)。解除したあとは壊せる。
- もう1つ別のシュルカーを本で触ると「登録をここへ移す」。移すと前の登録は解除される(1人1つ)。他人の専用シュルカーは本でもメニューが開かない。
- 登録したシュルカーを、ピストンで押す/コマンドで消す → 10秒以内に登録が解除され、持ち主に「無くなっていたため解除」と出る(オフラインなら、次のログインで1回だけ)。
- 持ち主が60日を超えて不在 → 登録が解除される(`/scriptevent bmh:policy set private_shulker_absent_days 14` で短くして試す)。
- 管理: `/scriptevent bmh:pshulker list`(一覧)、`release <プレイヤー名>`。
- 周りの設置禁止: 登録したシュルカーの2マス以内に、ホッパー・ピストン・ディスペンサー・ドロッパー・オブザーバー・レールを置こうとすると止まる(TNT・TNTトロッコ・リスポーンアンカー・エンドクリスタルは3マス以内)。遠く(ホッパーは3マス先)には置ける。
- 近くに禁止物があるシュルカーは、登録できない(「近くに hopper (x, y, z) があるため、登録できません」)。撤去すれば登録できる。
- 登録後に、コマンドやピストンで紛れ込ませた禁止物は、3秒ほどで撤去され(ブロックはアイテムとして落ちる)、持ち主に「禁止物を撤去しました(ブロック n 個、エンティティ m 個)」と出る。TNTトロッコは爆発せず、アイテムとして落ちる。
- 既知の穴: 禁止の範囲の外から、ブロックを一列につないだピストンで押されると、シュルカーが動く(動いたら見回りで登録が解除される)。

## 16. 取引所のエンジン(0.5.6。UIなし。コマンドで確認する)
準備: 専用シュルカー(§15)を登録し、小麦を入れておく。以下は `/scriptevent bmh:exchange ...`。
- `pull wheat 64`: シュルカーの小麦が取引所プールへ(名前つき・エンチャント・傷みのある品は対象外)。`pool` で確認。
- `offers wheat`: HRMHRMの常設出品(792個)が見える。`list wheat 10 <単価>`: 出品(単価はHRMHRMの売値以下)。輸送費(出品額の2%、最低1E)が口座から引かれる。`mine` で自分の出品、`cancel <ID> wheat` で取り下げ(輸送費は戻らない)。
- 別アカウントで `buy wheat 10`: 安い出品から買われ、代金が出品者の口座に入る(オフラインなら、ログイン時に入る)。買ったものは `inbox`。`deliver` で、買い手の専用シュルカーへ届く(専用シュルカーが無い・読み込まれていない時は入荷一覧に残る)。
- 自分の出品は買えない(HRMHRMの在庫から買われる)。残高が足りない時は買えない。
- 出品は14日で終わり、残りはプールへ戻る(`pool`)。HRMHRMの在庫は、1日に常設数の25%ずつ補充される(`refill` で即時に補充)。
- `/scriptevent bmh:account list` に `exchange` が出る。週が進むと、専用口座の週次の記録ができる。
- 注意: 郵便販売(書見台 + 紙)は、まだ今のまま動く。

## 17. 取引所のメニュー(0.5.7)
準備: 専用シュルカー(§15)を登録する。書見台に紙でタッチ → 取引所が開く(郵便販売の画面ではない)。
- 物品別リスト → 生鮮物 / 一般資源 / 希少資源: 品目と最安値・在庫が出る。無形資産は「準備中」。
- 品目 → 購入画面: 数量を入れて確認 → 買える。専用シュルカーに届く(未登録・読み込まれていない時は入荷一覧で待つ)。
- 残高が足りない時: カードがあれば不足分がリボになる(確認画面に出る)。カードが無い/停止中/限度額超えは、それぞれの案内が出る。プレイヤーの出品の分は、カードでは払えない。
- 出荷一覧 → 専用シュルカーから取り込む → プールの品を出品する(値段の上限=HRMHRMの売値、輸送費が引かれる)→ 自分の出品で取り下げ(プールへ戻る)。
- 別アカウントで、その出品が最安値なら先に買われる。売れた代金が出品者の口座に入る。
- 入荷一覧: 待っている品を「届ける」。シュルカーがいっぱいなら一部が残る。
- 本日のオススメ・カスタマーサービス(プライム・カード)・リーガルサービス: 以前の郵便販売と同じに動き、戻るで取引所に戻る。
- 希少資源 → 防具・本などの直接販売(HRMHRM)へ行ける。

## 18. 取引所の分類(0.5.8)
- 書見台+紙 / 鉄ブロック+植木鉢 / 苔ブロックの窓口の「取引所」ボタン、のどれからでも取引所が開く。
- 物品別リスト → 生鮮 / 一般資源 / 希少資源 → 小分類 → 品目。苗木・花・魚・肉は1品ずつ別に並ぶ。
- 出品のない品は「出品 0件」。ページに「あなたが最初の出品者です」と出る。
- 腐る品に [腐る:6日]/[腐る:12日]、腐らない品に [腐らない]、バルクの品に [バルク] が付く。
- 丸石・鉄インゴット・ダイヤなど(ゴーレムの現物取引にあった品)のページに「相場で取引」が出て、旧画面で売買できる。小麦などのページに「生鮮市場(GLB建て)」が出る。
- 表にない品(ブレイズロッドなど)は、取り込めても出品できない。
- 希少資源の小分類の下に、防具・エンチャント本の直接販売(HRMHRM)がある。

## 19. 相場の統合・検索・価格(0.5.9)
- 丸石・鉄インゴット・ダイヤなど(旧・現物取引の品)のページに「相場(システム): X E × 無制限」の行が出る。買うと、最安のもの(HRMHRM・プレイヤー・相場)から選ばれる。
- ダイヤを買うと相場が少し上がる(翌日にかけて戻る)。「相場で売る」(プールの品)で相場が少し下がる。
- [バルク]の品(丸石・鉄インゴット・原木など)は、相場から買うのも売るのも、1,728個(シュルカー1箱)単位。100個などの小口はHRMHRM・プレイヤーの出品から買う。1回の購入は5,184個まで。
- 残高が足りない時、相場やプレイヤーの分はカードで払えない(HRMHRMの分だけ)。
- トップの「品目を検索」: 「だいや」「ダイヤ」「diamond」「ボート」「いかだ」などで探せる。結果を選ぶと品目ページへ。戻るで結果に戻る。
- ボートは木の種類ごとに10種+竹のイカダ。ポプラのボートがゲーム内にあるか(なければ外す)。
- 銅の剣・ツルハシなどの値段が、鉄・ダイヤ・ネザライトより安い。

## 20. IDの修正・戻るスイッチ(0.5.10)
- 額縁・輝く額縁・ベッド・オークの棚・ジャック・オ・ランタン・小さなドリップリーフを、取引所で買うと、専用シュルカーに届く(以前の郵便販売では届かない恐れがあった)。旧カタログ(本日のオススメ以外のHRMHRM直接販売)のシュルカーボックスも届く。
- 数量・出品・検索の入力フォームの一番下の「戻る(オンにして送信)」をオンにして送信すると、1つ前の画面に戻る。銀行・株などの数量入力にも同じスイッチが出る。
- 棚は木の種類ごとに11種。



## 21. 村・会社の出荷 = 取引所への出品(0.5.11)
- 村の在庫に消費されない原料(棒・苗木・羽根・羊毛・鉄/銅の原石・木炭)が溜まった状態で、週が進むのを待つ(週の締めは自動。`/time set` や `/scriptevent bmh:account hrmhrm` で状況を見られる)。村の「在庫」画面の「先週の出荷」が「取引所へ出品(n個…)」になり、現金収入は増えない。
- 取引所のその品のページに、[村]村の名前 の出品が出る(相場より安く、HRMHRMの売値以下)。それを買うと、村の口座(管理メニューの資金)が買った分だけ増える。
- 会社も、在庫が保持数(640個)を超えた分が、[会社]会社の名前 として出品される。
- 売れ残りは14日で村・会社のプールに戻り、次の週にまとめて出し直される(出品は1品につき1本)。
- 従来の動きに戻すには、ポリシーの `exchange_entity_shipping` を 0 にする(週の締めに自動売却)。



## §22 NPC会社と価格順(0.5.12)
1. `/scriptevent bmh:npc` — 4社(NPCMCD・NPCCLT・NPCPPL・NPCEKB)の現金・在庫・依頼の数が出る。初日は現金が開業の資金(開発銀行)。
2. 掲示板の「会社」に、4社が距離に関係なく載る。原料の枠(小麦・牛肉・鉄インゴットなど)があり、受注 → 納品で代金が出る。
3. `/scriptevent bmh:npc run` で、その日の運用を今すぐ回す。納品した原料が加工され、取引所の製品(パン・矢・コンパスなど)に `[NPC]` の出品が並ぶ。
4. 取引所の品のページで、並び順が「プレイヤー → NPC → HRMHRM → 相場」になっている(同額のとき)。バルクの品で、相場がHRMHRMより安く先頭に出ない。
5. 取引所に原料(例: 牛肉)を出品しておくと、翌日 NPC が買って、売り手に代金が入る。
6. 政策 `npc_company_enabled` を 0 にすると、NPC会社が動かなくなる(冬眠)。


## §23 村の職業ブロックと手工業(0.5.13)
1. 村の鐘の周り(水平±64 / 高さ±32)に、燻製器・堆肥箱などを置く。村の近くで1日待つ(近くにプレイヤーがいる日に数える)。`/scriptevent bmh:core info <村のID>` の `jobs` に数が出る。
2. 村の管理 → 在庫の画面に「職業ブロック: 肉屋(燻製器) x2」などが出る。
3. 村のクエスト(入荷)の枠に、職業の原料(生肉・種など)が先に載る。納品すると、村の口座から代金が出る。
4. 週が変わると、村の加工が走る。取引所に、村の出品(焼き肉・小麦など)が並び、`[村]` と表示される。村の口座の週次記録に village_purchases(買った代金)が出る。
5. 取引所にその原料を出品しておくと、週の締めに村が買う(売り手に代金が入る)。
6. 職業ブロックのない村は、従来の固定の入荷表のまま。
7. 範囲外のチャンクが読み込まれていないとき、前回の数が残る(0にならない)ことを確認。


## §24 HRMHRMの取引所での仕入れ(0.5.14)
1. 取引所に、HRMHRMの常設品(例: 小麦)を、基準価格の90%以下で出品しておく。翌日、HRMHRMがそれを買い、売り手に代金が入る(出品が消える)。
2. 基準価格の90%を超える出品は買われない。
3. 政策 `hrmhrm_buy_budget_ratio` を 0 にすると、買わなくなる。

## §25 ポーション・エンチャント本・Witcha-Cola(0.6.0)
1. 取引所の「希少資源」にエンチャント本・ポーションの小分類が出る。名前が日英で正しい(例: 回復の強化ポーション、ダメージ増加V)。
2. HRMHRMの常設のエンチャント本を買うと、正しい種類・レベルの本が届く(受け取り箱に入る)。
3. 飲む/スプラッシュ/残留の各ポーションを買って、効果と配送の種類が合っていること(`Potions.resolve`)。
4. 自分のポーション・エンチャント本を出品して、共有シュルカーに入れる→出品→引き出し→受け取りが通ること(種類がずれないこと)。
5. Witcha-Cola(NPCWCC)が数日後にポーションを出品し、取引所で買えること。原料(砂糖・ネザーウォートなど)が足りないとき会社の依頼欄に出ること。
6. 価格の目安: 本・ポーションがHRMHRM常設より先に買われず、価格順(プレイヤー→NPC→HRMHRM→システム)になっていること。
7. NPC会社が5社(MCD・CLT・PPL・EKB・NPCWCC)動いていること。

## §26 品目名の一本化・アドオンの品(0.6.1)
1. 会社(Eekbay・Clattle・Pupple・McMoonald)の依頼欄・納品画面で、kelp・slime_ball・oak_planks・flint・cocoa_beans・milk_bucket・egg・beef が日本語で出る。
2. 専用シュルカーの取り込み画面で、Firework Rocket・Villager Spawn Egg(取引リストにない品)が出ていないこと(出るなら、その品の扱いを決める)。
3. 村の画面の職業ブロック名(コンポスター等)が日本語で出る。
4. 他のアドオンを入れたワールドで、`/scriptevent bmh:ext list` に、そのアドオンの品と似た品の対応が出る。取引所「希少資源」に「アドオンの品」が出て、出品・購入できる。
5. `bmh:ext alias <ID> <似た品>` で値付けを固定でき、`bmh:ext check` で履歴(`hist`)が増える。
6. ワールドを開き直したあとも、アドオンの品が取引所に残っている(保存のキー bmh_ext_items)。

## §27 アドオンの品の自動掲載・7日の値動き(0.6.2)
1. 他アドオンのアイテムを専用シュルカーに入れて「取り込む」と、取り込み画面に出て、取り込むと取引所「希少資源 > アドオンの品」にページができる(出品できる)。
2. 似た品がない品は、値付けなしで載る(`bmh:ext list` に listed, no price match)。出品価格は自由(上限10万E)。
3. 取引リストにないバニラの品(花火ロケット等)は、取り込み画面に出ない。
4. 品目ページに「直近7日の取引」の棒グラフ(株と同じ)と平均・変化(▲緑/▼赤)が出る。取引がなければ「なし」。一覧の品名の横に▲▼が出る。
5. 買った日の平均単価が、翌日以降のグラフに反映される(取引のない日は前の日のまま)。

## §28 取引リストにないバニラの品の自動掲載(0.6.3)
1. 花火ロケットを専用シュルカーに入れると、取り込み画面に出る。取り込むと「希少資源 > その他の品(自動掲載)」にページができ、出品・購入できる。
2. コマンドブロック・バリア・スポナー等は、取り込み画面に出ない。
3. 花火は飛行時間・星の有無で中身が違う(いまは区別せず1つの品)。ふつうの花火(飛行時間1・星なし)以外が混ざらないか(isPlainStack が弾く)。

## §29 導入クエスト(会社を建てるまで)と報酬(0.6.4)
1. 新しいプレイヤーで、導入クエストが 0/9 から始まる。画面の下に「報酬: …」が出る。報告すると報酬が渡り、メッセージが出る(持ち物がいっぱいなら足元に落ちる)。
2. 5つ目「専用シュルカーを登録する」: 登録するまで進めない(登録後に報告できる)。
3. 6つ目「取引所に出品する」: 出品に成功するまで進めない / 7つ目「取引所で買って受け取る」: 入荷を専用シュルカーへ受け取るまで進めない。
4. 8つ目「村と会社のしくみ」は説明のみ(報告で進む)。9つ目「会社を建てる」: 会社を登記するまで進めない。登記後に報告すると、ダイヤ4・ラピス32が渡り、導入クエストの欄が消える。
5. 旧版で4つ済ませた人に、5つ目からが出る。すでに専用シュルカー等が済んでいれば、すぐ報告できる。
6. 報酬の量が多すぎ/少なすぎないか(特にラピス・ダイヤ)。

## §30 鮮度のある食品の取引所対応(0.6.5。チケットA)
1. 専用シュルカーに、ふつうに持ち歩いた食品(鮮度の行が付いたもの。生鮮・加工の両方)を入れて取り込む。100%・80%以上は取り込める。
2. 鮮度が79%以下の品は、取り込み画面の下に「鮮度が足りないため受け付けられません」と出て、取り込めず、シュルカーに残る。ちょうど80%は通る。
3. 取り込んだ品を出品し、買って入荷を受け取ると、新しい鮮度で渡される(インベントリで持った時点から減り始める)。
4. 名前つき・エンチャント付き・傷んだ品は、これまでどおり取り込めない。腐った肉など鮮度の対象外の品に影響がない。
5. 鮮度品が出品されたあと、NPC会社(McMoonald など)が買う。

## §31 村専用の画面と物々交換(0.6.5。チケットB 1〜3)
1. 村(鐘)を触ると、「寄り合い所に行く / 蔵の門番に尋ねる / 村長の部屋に行く」の3つが出る。会社(ロードストーン)は従来の6つのまま。
2. 寄り合い所: 「仕事を聞いてみる」に職業ブロックと作れるもの・1日の回数。「掲示板のことを聞く」に村の資金・今日の必要数・受注の状況。
3. 「欲しいものはないか聞く」: 今日の枠の品を手持ちから渡し、蔵の品と交換できる(数量の入力 → 受け取る品を選ぶ)。渡した分が枠の「あと○個」から減り、同じ品を納品クエストで二重に受けられない。蔵が空だと「交換に出せる品がない」。
4. 蔵の門番: 蔵の在庫・先週つくった品・取引所に出している品(単価・残り日数)が出る。
5. 村長の部屋: 人数・村の懐事情。登記した人だけ「契約を切る」から解散できる(払い戻しは従来どおり)。ほかの人には断りのメッセージ。
6. 物々交換のレート(既定0.9。`village_barter_ratio`)が、体感で村に有利すぎ/不利すぎないか。

## §32 職業ブロックの検知の修正(0.6.6。チケット1〜4)
- 村の範囲に堆肥箱・燻製器などを置いて近くにいる → `/scriptevent bmh:core info` で `jobs` と `jobsDay` が出る(0件でも `jobs: {}` が残る)。
- 検知専用のブロック(機織り機・石切台など)だけの村 → 寄り合い所「仕事を聞いてみる」に「いまは何も作らない」付きで出る。何もないときだけ「まだ見つかっていない」。
- シミュレーション距離を絞って離れた角を読み込み外にする → ログに部分読み込みの警告が出て、前の記録が減らない。
- 物々交換: 連続で多数交換しても注文が300件で断られる(通常の受注と同じ)。
- 村長の部屋の人数が、`core info` の `pop` と一致する。

## §33 女王歴・記念日・村のイベント(0.6.6。チケットB 4〜6の一部)
- 取引所・電子取引所のメニューの先頭に「女王歴 N年M月D日」が出る(HUDには出ない)。21日で1月、12月で1年。
- 記念日(3/21・5/17・10/7)の日に、村メニューに記念日の行が出て、受け取ると小さな贈り物が出る。
- 戦勝記念日: 最初に村の英雄を得た日付が記録され、同じ月日になると全員に村の英雄が付く。村民の日: 村人が初めて20人に達した日が記録される。
- 蔵が上限(既定1024個の総数)の75%以上で「運んでよ」が出る。手持ちでもシュルカーでも運べて、期限は2週間、報酬は頼んだ先の村が払う。鮮度80%以上で満額、50%以下で半額。緊急調達は単価×1.5。

## §34 村の地域タイプと特産品(0.6.7)
- 村長の部屋に「地域: ○○の村(型)・特産・適性・蔵の上限」が出る。平原・砂漠・サバンナ・タイガ・雪原・海の各バイオームで鐘を置いて確認(バイオームIDの実機での突き合わせが未了)。
- 週の締めのあと、蔵の門番の「先週作った品」に特産品が出て、取引所に村の出品として載る。
- 砂漠は木と食料、雪原は炭、タイガは炭と鉄・銅の原石が、掲示の入荷の枠に出やすい。雪原の蔵上限は2倍(既定2048)。

## §35 カレンダー表示と村同士の取引(0.6.9)
- `/scriptevent bmh:calendar` で、今日の日付・戦勝記念日・村民の日(未登録/登録日)・次の記念日がチャットに出る。
- 取引所のメニュー「カレンダーを見る」に、固定の3祭とあと何日かが出る。村長の部屋の「カレンダーを見る」に、戦勝記念日と村民の日の登録状態が出る。
- 週の締めのあと、砂漠・海などの村の蔵の門番に「先週、取引所で仕入れた品」が出る(取引所に出品があるときだけ)。村の口座から代金が引かれる。
