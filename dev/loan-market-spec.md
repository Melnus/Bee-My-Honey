# 借入依頼の掲示板・送金・制限(0.5.3)

実装: `economy/loan-market.js`(掲示板・貸付・返済の配達)、`economy/transfer.js`(送金)、`economy/entity-stock.js`(物資を先に売る)。
検算: `dev/check_loan_market.mjs`。実機の手順: `dev/real-device-checklist.md` の §14b〜14c。

## 1. 流れ
- 借りる側: 銀行(審査あり・即時)か、貸し手の募集(審査なし)。募集は1人1件。条件(金利・返済見込)は信用スコアから `getLenderRate(getRepayProbability(score), 週数)`。
- 貸す側: 掲示中の依頼(個人・村・会社)を先に、窓口のNPC候補をその下に並べる。貸付は同時に1件(既存どおり)。
- 引き受けると、貸し手から引き(`p2p_lend`)、借り手に入る(`p2p_borrow`)。借り手は `cr_loan_*`(銀行のローンと共用)に `cr_loan_lender` / `cr_loan_lid` が入る。村・会社は口座の現金・負債・`loans[]` に入る。
- 返済: 個人は週次(`applyLoanBilling`)で、借り手から貸し手へ(`p2p_repay` → 貸し手に `p2p_return`)。村・会社は週の締め(`settleEntityLoans`)。貸し手がオフラインなら郵便受け(`bmh_loan_mail`)に入り、ログイン・貸す/融資管理を開いた時に届く。
- 台帳: `p2p_*` と `transfer_*` は市場グループ(お金の移動であり、発行でも回収でもない)。HRMHRMの債権・負債には入らない(銀行のローンとは混ぜない)。

## 2. 掲示の期限
- 依頼は、掲示から7日以上たった最初の週の締めで消える(実際には7〜13日)。
- 村・会社の依頼が消えた時、現金が運用の下限(`minReserveBase`)を割っていれば、介入案件(`loan_unfilled`)にする。会社は既存の「介入案件あり → 強制解散」、村は `runUpkeep` で強制解散(清算)。通常は開発銀行機構の支給があるので起きにくい。

## 3. 村・会社の依頼
- 不足 = 目標準備金 × 2 − 自由に使える現金(現金 − 予約額)。不足があれば、まず在庫の物資を売る(高い物から。売値 = 基準価格 × 掛率 × `pool_sale_ratio`)。足りない分だけ、資産の半分以内の段で依頼にする。依頼は1件、借入は2件まで。
- 資産 = 純資産(貸借対照表の equity)+ 在庫の価値。
- 返済できない週が4週続くと貸し倒れ(貸し手のスロットが空く)。解散・登録解除の時は、残った現金から貸し手へ先に返し、残りは貸し倒れ(口座が消える時のフックで通知)。
- 村の解散では、残った現金はHRMHRMへ戻る(代表者へは払わない。支給金の持ち逃げ防止)。

## 4. 制限と悪用対策
| 対策 | 内容 | 設定値 |
|---|---|---|
| 借りられる額 | 純資産(口座・外貨・株 − 借入)の半分まで | `loan_borrow_asset_ratio` 0.5 |
| 貸せる額 | 貸し手の資産の半分まで(1件あたり) | `loan_lend_asset_ratio` 0.5 |
| スコアの水増し | 個人間ローンの完済では信用スコアを上げない(減点は残る) | — |
| 貸し手のスロット | 期間+猶予を過ぎても完了の知らせが無ければ貸し倒れで閉じる | `loan_lend_grace_weeks` 4 |
| 取り違え | 通知は貸付ごとのID(`lid`)で照合。IDは増え続ける(再利用しない) | — |
| 送金 | 手数料(HRMHRMの収益)と1日の上限。相手はオンラインのみ | `transfer_fee_rate` 0.02 / `transfer_daily_cap_base` 2000 |

## 5. 長期不在・改名
- 貸し手・借り手・口座の識別はプレイヤーID。名前は表示だけ(古い名前が残るのは貸し手の画面だけ)。
- 村・会社の注文はIDで照合(古い注文は名前)。期限切れの注文は予約額に数えない。
- 郵便受けが溢れても、受け取るお金は残る通知へ合算する。戻らない人の郵便受けは残り続ける(額は小さい)。

## 6. 未対応・今後
- 先物の証拠金など、個人の資産にまだ入れていないもの(口座・外貨・株だけ)。
- 相手を指名した融資。オフラインの相手への送金。
- 村の「その日の枠」の乱数の種が名前ベースのため、改名するとその日の品目が入れ替わることがある。
