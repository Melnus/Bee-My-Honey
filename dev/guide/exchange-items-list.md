# 取引所の取引リスト(3分類版)

合計 285 品目(生鮮 16 / 一般資源 190 / 希少資源 79)

## 凡例

- ◆ = 現行の生鮮市場・一般資源・希少資源の画面にすでにある品目(そのまま取引所へスライド)
- ※ = 価格レシピ未設定(汎用の採集値で計算される)
- [腐る:6日] = 未加工の生鮮物。インベントリ内で6日(市場に出品中は7日)かけて鮮度が落ち、腐ると腐った肉になる
- [腐る:12日] = 加工品(焼き物・調理品・スープなど)。インベントリ内で12日(出品中は21日)
- [腐らない] = 砂糖・ハチミツ系・菓子類・金の食べ物・通貨系フルーツ。鮮度の対象外
- [腐らない(28日で取り下げ)] = 鮮度の概念がなく、出品から28日で取り下げられる品(生コンブ)
- [鮮度要確認] = 食べられるが腐敗テーブルに未登録の品。腐らせるかどうかを決める
- [バルク] = シュルカー単位(1,728個)のバルク取引専用の品(16品)。希少資源の5品は従来どおり小口の現物取引

## 分類ルール

- 現行画面にある品目はその分類のまま取引所へ移す
- あぶれた鉱物資源・植物資源・加工品類は一般資源
- レッドストーン製品と武具・防具は希少資源

- 分類の一覧では、現行の生鮮市場と同じく「出品 0件」の形で表示する(案)

- 案: ひらがなとカタカナの違いは検索前にそろえる。英語表示の名前でも探せるようにする
