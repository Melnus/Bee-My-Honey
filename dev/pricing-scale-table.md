## 0. 訂正: 「約1/8に圧縮」は正確ではなかった
`pricing-settings.md` §6-1 では「ダイヤ12→1.5Eなので全体が約1/8に圧縮」と書いたが、ダイヤだけを見た説明だった。0.4.2と実測で比べると:

|---|---|---|

| バルク: 鉄 / 銅 / ラピス / レッドストーン | 1.5→0.407 / 0.8→0.282 / 1.5→0.375 / 1→0.25 | 0.21〜0.35 |

| バルク: 砂・砂利 / 土 | 0.03→0.188 / 0.02→0.188 | 6.3 / 9.4(**上がった**) |
| バルク全体の中央値 | | 0.54 |
| 郵便販売(161品) | 10〜900,000E(中央値20,000E) → 1〜78E(中央値5E) | 単価の比の中央値 約1/1,600(桁が違う) |

結論: **一様な縮尺の変化ではなく、価格の根拠を作り直した結果**。高価な素材は大きく下がり、安価な素材は上がった。
郵便販売は旧価格が「円の金銭感覚」(送料2Eと同居できない桁)だったので、そもそも名目額との整合は取れていなかった。
→ 「1/8を掛け戻す」ような機械的な調整は成り立たない。名目額は**新しい価格体系の中での重さ**で個別に見直す。

## 3. 見えたこと
1. **価格改定の副作用で確実に崩れているのは「保険」**。支給品が価格改定で大きく安くなったのに、保険料は据え置き。支給の価値が保険料の2〜6割しかない。
2. **「カード最低返済」と「プライム週額」は、週収入(約70E)と比べて重い**。縮尺というより、収入の物差しが新しくなったことで見えた。
3. **配当(KLH)の5%/日は縮尺とは無関係に突出**(週35%)。インフレ・金利連動を入れると目立つので、早めに判断したい。
4. 融資・カードの上限は、価格帯(最大78E)に対して桁が大きい。ただし高額な品を買う用途(将来の取引所・不動産)を見据えた大きさとも読める。
5. 銀行金利・カード金利・配当率などの**比率で持っているものは縮尺の影響を受けない**。直す対象は金額(E)で持っているものだけ。

## 4. 次の段階(案)
- 物価指数(「定番のかご」)を決め、名目額を「手間賃の何日分」で持つ形にする(インフレ連動の入れ物にもなる)。
- 直す優先順: ①保険(支給品と保険料の釣り合い) → ②カード最低返済・プライム週額 → ③配当率(別問題) → ④融資/カード枠の上限。
- 既存ワールドの扱い(残高を変換するか、0.5系を新規ワールド推奨にするか)は、金額を直す前に先に決める。
